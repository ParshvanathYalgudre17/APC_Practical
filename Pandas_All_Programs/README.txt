PANDAS ALL PROGRAMS

This folder contains Python programs for all questions from the Pandas practical document,
along with sample CSV files required for the CSV-based questions.

Files:
- Q01 to Q07: Dictionary and DataFrame programs
- Q08 to Q12: Pandas Series programs
- Q13 to Q16: CSV file programs
- students.csv, employees.csv, patients.csv, weather.csv: sample datasets

Requirements:
1. Install Python.
2. Install Pandas by running: pip install pandas
3. Keep the CSV files in the same folder as the Python scripts.
4. Run each .py file separately.

Note: The source document numbers some questions repeatedly, so filenames are numbered
continuously to make all programs easy to identify.
