NUMPY ALL PROGRAMS

This folder contains separate Python files for all 25 questions in NumPy.docx.

How to run:
1. Install Python.
2. Install NumPy by running: pip install numpy
3. Open a Qxx_*.py file in your Python editor.
4. Run each program separately.

Questions Q01-Q17 cover 1D arrays, arithmetic, indexing, matrices, slicing,
sorting, concatenation, and student marks.
Questions Q18-Q25 cover 3D arrays, array statistics, and flattening.

Random-array questions produce different values each time they run.
For Q20, row and column sums are shown for each layer of the 3D array.
